# eCommerce Mobile App

This folder contains a React Native mobile app scaffold for iOS and Android.

## Structure
- `App.js` — root navigation and layout
- `screens/` — app screens for home, categories, product details, cart, and profile
- `components/` — reusable UI components
- `data/` — sample product and category data

## Run locally
1. Install dependencies:
   ```bash
   cd ReactNativeApp
   npm install
   ```
2. Start the Expo development server:
   ```bash
   npm start
   ```
3. Run on a simulator or device:
   ```bash
   npm run android
   npm run ios
   ```

## Notes
- All mobile app code lives inside `ReactNativeApp`.
- No changes were made to website or admin code outside this folder.
